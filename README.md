## Условие задачи

### Задание 6. Повороты в пространстве через кватернионы

Реализовать класс `Quaternion` и использовать его для поворота 3D-векторов:

- Арифметика кватернионов: сложение, умножение, сопряжение, норма.
- Поворот вектора по формуле q v q⁻¹.
- Тесты на корректность поворотов и композиции.

Внешние библиотеки для математики кватернионов использовать нельзя; `pytest` и `math` — можно.

---

## Запуск тестов

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install pytest
pytest
```
